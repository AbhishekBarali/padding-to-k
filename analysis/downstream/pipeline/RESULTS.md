Measures (n = the frozen answer list's count of true items):

1. **False alarm**: documents with no true item, k = 1: share of outputs with at least one substantive entry (%). Change against `none` in points.
2. **Collection count**: documents with n < k, k = 3 and 5: total substantive entries / total true items in the cell (1.00 is correct). Change against `none` in the same units.

A level is a ratio of sums over all ok outputs of the condition in the cell (MISSING outputs left out, unreadable outputs counted with 0 entries). A change against `none` uses the (model, document, k) units with an ok output under both conditions, a prose condition's wordings averaged first, as in the registered paired tests.
